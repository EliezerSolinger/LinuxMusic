Drag a value up or down (Shift: fine); double click to type it. = Arraste um valor para cima ou para baixo (Shift: fino); duplo clique para digitar.
Oct + = Oit +
Oct − = Oit −
Duplicate = Duplicar
Delete = Apagar
Click draws, drag sets the length; drag a note to move it, its edge to resize; Shift at the start of a drag copies; Alt ignores the grid; right button erases. = Clique desenha, arrastar dá o tamanho; arraste a nota para mover, a borda para redimensionar; Shift no começo do arrasto copia; Alt ignora a grade; botão direito apaga.
Drag a rectangle; Shift toggles; Ctrl/Cmd+A selects all, Esc none. = Arraste um retângulo; Shift alterna; Ctrl/Cmd+A seleciona tudo, Esc nada.
Click or drag over notes to erase them. = Clique ou arraste sobre as notas para apagar.
Drag on a note to draw its pitch bend; right button keeps only the first point. = Arraste sobre uma nota para desenhar a afinação; o botão direito deixa só o primeiro ponto.
Drag a line, diagonal or not, across the notes to cut them; Shift on release drops the short ends; Esc cancels. = Arraste uma linha, diagonal ou não, sobre as notas para cortar; Shift ao soltar tira os pedaços curtos; Esc cancela.
Drag a chord sideways: its starts spread in a staircase. = Arraste um acorde para o lado: os inícios se espalham em escada.
