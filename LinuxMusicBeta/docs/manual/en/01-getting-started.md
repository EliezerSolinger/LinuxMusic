# Getting started

LinuxMusic has two pages: Composition (Ctrl+1) and Mixing (Ctrl+2). The MIDI maps page (Ctrl+3) binds MIDI controls to any knob.

- New project: File > New (Ctrl+N). Open: Ctrl+O. Save: Ctrl+S.
- Play and stop: Space. To the start: Home. Loop: L.
- The big transport display shows the position; one click changes its format (bars, time, samples, timecode).
- Change the tempo by dragging, with the wheel, or by tapping the Tap button (Tools > Tap Tempo).
- Ctrl+K opens the command palette: every command of the program is in it.
