# Instruments and effects

Each instrument track has a window of its own. Each desk insert has the effect's window.

- The Browser (Ctrl+8) lists instruments, effects, samples and projects; Enter sends the item to the active track or channel.
- View > Detach puts the current window in a system window; closing it docks it back. What is detached is remembered in the project.
- Third-party plugins run outside the program: if one fails, the rest goes on and a notice offers to recreate it.
