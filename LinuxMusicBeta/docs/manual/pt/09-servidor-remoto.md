# Servidor remoto

O núcleo do programa pode rodar sem janela, em outra máquina, e a interface se conectar a ele pela rede. A interface é a mesma: o que muda é só onde está o áudio.

- Os caminhos de arquivo são os da máquina do núcleo; por isso os diálogos de arquivo do sistema não aparecem e as telas Projeto e Exportar pedem o caminho por escrito.
- Telemetria (medidores, posição, carga) chega junto com as mudanças do projeto.
